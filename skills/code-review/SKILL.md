# Code Review Skill

Review submitted code for:

1. Logical errors.
2. Security vulnerabilities.
3. Performance bottlenecks.
4. Code duplication.
5. Poor exception handling.
6. Maintainability issues.

## Output format

- Findings
- Severity
- Explanation
- Recommended fixes
- Overall assessment
