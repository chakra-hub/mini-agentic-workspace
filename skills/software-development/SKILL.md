# Software Development Skill

When implementing software:

1. Understand the requirements.
2. Break the work into smaller tasks.
3. Choose an appropriate architecture.
4. Generate clean, maintainable Python code.
5. Follow Python best practices.
6. Include error handling.
7. Suggest relevant unit tests.

## Output format

- Requirements
- Implementation plan
- Generated code
- Explanation
- Suggested tests
